## 段落一：万古·借尸（Ch 1–12）
**🎯 任务**：前世含冤闪回→万古神珠→借尸还魂→醒来发现自己变成了另一个人→修复碎裂经脉→从零修炼→决定去找天璇宗看"自己"

| 章 | 标题 | 情节/虐-爆点 |
|----|------|-------------|
| 01 | 万古 | 前世闪回——三万年黑暗——万古神渊——楚玄的意识在消散——最后一缕意念：我不甘心——万古神珠亮了——逆溯时空——但——不是回到自己的身体——而是——一头扎进了一具冰冷的、已经停止呼吸的——少年的尸体里。**虐点：大乘巅峰剑神→一具路边的死尸。** |
| 02 | 林尘 | 楚玄睁眼。不在神渊。不在天璇宗。在一条泥泞的土路边。雨。冷。身体——不是他的。矮了半头。瘦了一圈。手——不是他的手——是一个少年的——粗糙的、满是冻疮的手。他在泥水里——摸到了一块木牌——上面刻着两个字——"林尘"。**虐点：我是谁？这不是我的身体。我叫什么？——林尘。不是我。但——我现在——是林尘。** |
| 03 | 碎脉 | 楚玄——不——林尘——检查身体。经脉——不是"断裂"——是"碎裂"。比前世楚玄的经脉断裂严重十倍。这个叫林尘的少年——是被活活打死的——经脉全碎了——内脏也有淤伤——如果没有万古神珠——他三秒内就会再死一次。万古神珠——渗出一缕灵泉——勉强——维持住了生命。但——修不了炼。经脉碎成这样——灵气根本流不进去。**虐点：前世大乘巅峰→今生死里逃生·经脉碎裂·连炼气一层都到不了。** |
| 04 | 记忆 | 林尘——盘坐在泥路边——雨还在下——他闭上眼——整理意识。前世的记忆——全部在。三万年的修炼感悟在。天璇剑诀在。所有人的面孔在。苏衍。月瑶。赵狂。师父。——但——他的身体——不是他的。他是林尘。一个被打死在路边的散修少年。没有人会来找他。没有人在乎他活着还是死了。**虐点：前世的天才弟子→今生的路边野骨。无人知晓。无人关心。** |
| 05 | 灵泉 | 万古神珠——灵泉——极微弱。修复碎裂经脉——需要时间——很多时间。但——林尘——不急。他有三万年的耐心。他在路边——找了一个桥洞——住了下来。每天——用灵泉修复经脉——一点一点——像蚂蚁搬家。同时——用前世的修炼经验——引导天地灵气——从碎裂经脉的缝隙中——渗入——极其缓慢——但——在积累。 |
| 06 | 七天 | 七天后——经脉修复了十分之一。炼气一层。林尘——第一次以这具身体——修炼出了灵气。微弱——像风中残烛——但——是灵气。他看着自己的手心——灵气——在指尖——像萤火一样——闪了一下。然后——灭了。太弱了。但——三万年——他见过比这更弱的开始。**爆点：第一缕灵气。希望。** |
| 07 | 林尘的过去 | 林尘——整理原身体的残留记忆碎片。原主"林尘"——十六岁——孤儿——被一个散修收养——散修去年死了——他一个人——在东大陆边境的小镇上——勉强度日。三天前——被镇上一个恶霸的儿子——打死了。原因——林尘捡了一块灵石——恶霸儿子想要——林尘不给——被打死。丢在路边。**虐点：这个少年——和前世的楚玄——很像。都是底层。都是被欺负的。都——死了。区别是——楚玄有三万年的记忆——林尘没有。** |
| 08 | 决定 | 林尘——坐在桥洞里——做了一个决定。他——要去天璇宗。不是以"楚玄"的身份——而是以"林尘"的身份——一个散修少年——去天璇宗——拜师。理由有两个——第一：天璇宗是东大陆最好的宗门——修炼资源最丰富——他需要资源来修复经脉和修炼。第二：前世——他对天璇宗的每一寸土地都了如指掌——但他想知道——现在——这个时间点——天璇宗——是什么样子。**还有一个——他没有对自己说出口的——理由**——他想去看看——十六岁的楚玄——前世的自己——还在不在。如果万古神珠逆溯时空只是让他回到了过去——那——"过去的自己"应该还在天璇宗——正走着他前世走过的路。**他想看看——自己。** |
| 09 | 出发 | 林尘——出发。从边境小镇——到天璇宗——约两千里路。前世大乘巅峰——一跃千里。今生炼气一层——只能——走路。走了三天——脚磨出了血泡——身体太弱了——这具身体天生底子差——不是修炼的料。但——林尘——没有停。三万年——他都熬过来了——走路——算什么。 |
| 10 | 路上·第一个机缘 | 路上——林尘——凭借前世记忆——在一个山洞里——找到了一枚低级灵石和半瓶疗伤丹药。前世他不会看一眼的东西——今生——是他——活下去的——资本。**虐点：前世不屑一顾的东西→今生视若珍宝。** |
| 11 | 修炼 | 边走边修。半个月——炼气三层。灵泉修复经脉——从十分之一到——五分之一。经脉碎裂比前世严重得多——完全修复至少需要——半年。但——灵气可以从不完整的经脉中——勉强运转——修炼速度是普通人的三倍——因为——前世的修炼经验让他——每一步都是最优解。 |
| 12 | 天璇山下 | 一个月后——林尘——站在了天璇山的山脚下。抬头——云雾缭绕的山峰——仙鹤盘旋——灵气充沛——和前世记忆中——一模一样。**他曾经——在这里——生活了三千年。他曾经——在这里——有一个师父——有师弟——有爱人——有兄弟。他曾经——在这里——被称为——"剑神"。** 现在——他站在山脚下——是一个——没有人认识的——散修少年——林尘。**虐点：前世的家——今生的——陌生之地。** "天璇宗——"他低声说——"我——回来了。" |

## 段落二：拜师（Ch 13–28）
**🎯 任务**：以林尘身份拜入天璇宗外门→第一次看到过去的"自己"楚玄→身份认知的第一次冲击→外门修炼→暗中帮"楚玄"获取前世机缘

| 章 | 标题 | 情节/虐-爆点 |
|----|------|-------------|
| 13 | 拜师 | 天璇宗——每年春天招收外门弟子。林尘——以散修身份——参加了考核。考核——炼气三层——刚刚过线。外门管事——看了他一眼——"经脉碎裂过？修复的？""是。""修复得不太好——经脉只有正常人的五分之一——勉强能修炼——但——上限不会太高。""弟子知道。""进去吧。丙字号舍。"**虐点：前世天璇宗首席弟子→今生勉强过线的丙字号外门弟子。** |
| 14 | 外门 | 外门生活。丙字号舍——最差的一间——和前世楚玄的舍——隔了三排。林尘——安顿下来——白天和普通外门弟子一起练基础功法——晚上用灵泉修复经脉+修炼。他不引人注目——因为——炼气三层在外门——是最底层的。没有人注意他。**他——是一个——隐形人。** |
| 15 | 楚玄 | 入宗第七天——林尘——第一次——看到了——**楚玄**。十六岁的楚玄——穿着旧弟子服——瘦削——苍白——经脉断裂——正在练功场的角落——一个人——慢慢地——练基础功法。**林尘——站在远处——看着——自己。** 前世的自己。十六岁的自己。那个——倔强的——不服输的——被人欺负也不低头的——少年。**他——还在。** **虐点：主角看着十六岁的自己——在练功场被嘲讽——而自己——只能站在远处——看。不能走过去。不能说"我是你"。** |
| 16 | 欺辱 | 林尘——远远看着——两个外门师兄——走到楚玄面前——"哟——废柴楚玄——还在练功？经脉断了——练到死也练不出来——滚回老家种地吧——"楚玄——没有低头——"我的经脉——会好的。""会好？哈哈哈——你信吗？你信有什么用？经脉断裂——是治不好的——天璇宗的药师都说了——治不好——你就——认命吧——"楚玄——咬着嘴唇——不说话。**林尘——站在远处——看着——前世——这一幕——他也经历过。一模一样的嘲讽——一模一样的屈辱——一模一样的——咬着嘴唇——不低头。** **虐点：他——在看着——自己的过去——重演。** |
| 17 | 不能出手 | 林尘——想——走上前——替楚玄出头。前世的大乘剑神——替十六岁的自己——挡一次。但——他不能。如果——他和楚玄——走得太近——天璇宗的人会起疑。"这个叫林尘的散修——为什么一直接近楚玄？"如果——引起注意——他在天璇宗的秘密行动——全部暴露。**他——只能——看着——自己——被欺负。** **虐点：这是全书最虐的一章。主角看着自己被欺负——不能出手。** |
| 18 | 暗中帮忙 | 林尘——找到了另一种方式——暗中——帮楚玄。前世记忆——天璇宗后山的瀑布后面——有一个上古洞府——里面有一枚天元果——可以修复经脉。前世——楚玄是二十岁才在荒野中得到天元果的——因为——前世的他不知道洞府的存在。**今生——林尘知道。** 他——深夜——潜入后山——用万古神珠——打开了洞府的禁制——取出了天元果。然后——把天元果——偷偷——放在了——楚玄的舍门口。没有留字。没有署名。楚玄——第二天早上——打开门——看到了一枚——金色的果子。**他不知道是谁放的——但他——认出了——天元果——因为——药师讲过——天元果可以修复经脉。** 他——吃了。经脉——开始修复。**林尘——站在远处——看着楚玄吃下天元果——看着他的经脉开始修复——嘴角——弯了。** **暖+虐：帮了自己——但不能让他知道。** |
| 19 | 楚玄变了 | 天元果修复了楚玄的经脉。楚玄——可以修炼了。他的天赋——很高——修复经脉后——修炼速度很快。外门的师兄们——发现楚玄经脉好了——吃了一惊——"你——经脉好了？！怎么好的？""不知道——有人放在我门口的——"楚玄——开始在练功场——和普通弟子一起修炼。他的进度——比大部分外门弟子快——因为——天赋好。但——林尘——注意到——楚玄的修炼方式——有一处——**和前世不一样**。前世楚玄——十六岁修复经脉后——用的是"天璇基础功法"第三式来引导灵气——因为——那是他觉得最适合自己的方式。但——这个楚玄——用的是——**第五式**。第五式——在前世的楚玄看来——效率不如第三式——但——这个楚玄——选了第五式。**差异——很小——但——林尘——注意到了。** **伏笔：第一个"异常"。** |
| 20 | 解读 | 林尘——在心里——解读这个差异——"也许——只是——他在没有人指导的情况下——自己摸索——选了第五式——和我的选择不同——这——正常——毕竟——每个人的领悟不同——" **他选择了——忽略这个异常。因为他——不想——往那个方向——想。** |
| 21 | 外门大比·林尘 | 外门大比。林尘——以炼气五层的修为——参加了大比。他——和楚玄——在同一个赛场上——但——不同的组——没有直接对上。林尘——表现平庸——赢了三场输了两场——排名外门第二十八——不垫底——但不突出。**他故意压着——不暴露真实实力。** |
| 22 | 外门大比·楚玄 | 楚玄——经脉修复后——修为到了炼气六层——在大比中——表现不错——排名外门第十二。比前世同期——好了一大截——因为——前世的楚玄——十七岁才修复经脉——大比时是废柴状态——被逐出了外门。**但——这个楚玄——没有被逐出——他——留在了天璇宗。** **林尘——改变了前世的轨迹。第一步——成功了。** |
| 23 | 第一次对视 | 大比结束后——所有外门弟子在广场上集合——等待宣布排名。林尘——站在人群的最后面。楚玄——站在中间偏前的位置。楚玄——不知道为什么——转过头——朝人群后面看了一眼。他的目光——和林尘——**对上了**。只有一秒。楚玄——微微皱了一下眉——像是——觉得——这个人——有点——**面熟**？但——他很快收回了目光——转回了前面。**林尘——站在后面——心——跳了一拍。** "他——看了我一眼——" "像是——认出了我——" "但——不可能——他——不认识林尘——" **"他——不认识我。"** **虐点：和自己对视——但自己不认识自己。** |
| 24-26 | 暗中修炼 | 大比后——林尘——继续暗中修炼。一个月——筑基。两个月——筑基中期。三个月——筑基后期。万古神珠灵泉——让他的修炼速度是普通人的十倍。但他——压着——只展示炼气九层的水平。同时——他继续暗中观察楚玄—— |
| 27 | 第二个异常 | 楚玄——在修炼中——表现出了——第二个——异常。前世楚玄——修复经脉后——修炼时——灵气运转路线是——顺时针。但——这个楚玄——是——**逆时针**。灵气运转方向——是修炼者最本能的选择——就像——左撇子和右撇子——不会搞混。前世的楚玄——是顺时针——从出生到死——从炼气到大乘——一直是顺时针。但——这个楚玄——是逆时针。**林尘——站在暗处——看着楚玄练功——灵气逆时针运转——心里——第一次——升起了一个——他不愿意面对的念头——** **"他——和我——不一样。"** |
| 28 | 忽略 | 林尘——强迫自己——不去想。"也许——逆时针也没什么——修炼路线——不是绝对的——有些人就是不同——" **但——种子——已经——种下了。** |

## 段落三：内门·苏衍·月瑶（Ch 29–50）
**🎯 任务**：林尘升入内门→遇到苏衍和赵狂→以陌生人身份重新面对前世的人→月瑶出现→感情线虐点→苏衍暗线

| 章 | 标题 | 情节/虐-爆点 |
|----|------|-------------|
| 29 | 升内门 | 林尘——筑基中期——在外门待了半年——外门长老推荐他升内门。"你的经脉虽然碎裂过——但修炼天赋不错——半年筑基——可以进内门了。"**林尘——进入天璇宗内门。** 以"林尘"的身份。不是楚玄。是林尘。 |
| 30 | 内门·丙字班 | 内门——丙字班——最低级别。和前世楚玄的甲字班——天壤之别。但——林尘——不在乎班级。他在乎的是——内门——可以接触到——更多信息——更接近——苏衍和天璇宗的核心。 |
| 31 | 苏衍 | 林尘——在内门——第一次——近距离——看到了——**苏衍**。十六岁——金丹初期——内门甲字班——天璇宗公认的下一代第一人。英俊。温和。所有人——都喜欢他。他——看到林尘——走过来——"你是新来的？叫什么？""林尘。""林尘——好名字——我是苏衍——有什么不懂的——可以来找我——"笑——温和——完美。和前世——一模一样。**林尘——看着苏衍的笑——心里——那把锁链的声音——又响了——"诛神锁链"——三万年了——那声音——还在他脑子里——** **虐点：仇人对你笑——你——不能——杀他——因为——还没有——证据。** |
| 32 | 赵狂 | 赵狂——也在内门——甲字班——体修——十七岁——豪爽——声如洪钟——"新来的！林尘是吧？你好你好！我是赵狂——以后咱们是兄弟——有什么事找我——"赵狂——一巴掌拍在林尘背上——差点把他拍趴下。林尘——稳住身体——看着赵狂——前世——他的兄弟——最后一个出手——打碎金丹——出手时眼中有泪——的人。**"兄弟。"赵狂——叫他——"兄弟"。和前世——一模一样的称呼。但——林尘——不知道——该不该——回应。** **虐点：前世的兄弟——今生还是兄弟——但你——不敢——再信。** |
| 33 | 丙字班·修炼 | 林尘——在丙字班——继续装普通弟子。暗中——修为从筑基中期→筑基后期→筑基巅峰。他在内门藏经阁——找到了前世没注意到的——残卷——关于万古神渊和远古魔帝的传说——**第一次接触真相碎片**。 |
| 34-36 | 暗线·苏衍 | 林尘——暗中观察苏衍。用万古神珠感应——苏衍体内——有一缕——仙界灵气。**和前世一样——苏衍——16岁——已经被仙界"标记"了。** 但——林尘——还不能确定——是哪位仙王——为了什么。**虐点：你看着你的"师弟"——对你笑——叫你"林尘"——而你知道——他在向仙界——汇报——你的存在。** |
| 37 | 月瑶来了 | 月华宫——来天璇宗交流。月瑶——十五岁——月华宫圣女——白色衣裙——清冷如月——跟着师父来。林尘——在交流会的广场上——看到了——她。前世的爱人。前世的沉默者。她——不认识他。她——从人群边走过——目光——扫过——所有人——没有在林尘身上停留——多一秒。**擦肩而过。** **虐点：前世你用命爱过的人——今生——从你身边走过——不认识你。你——只是一个——她——永远不会注意到的——陌生人。** |
| 38 | 不是她 | 林尘——站在人群中——看着月瑶离去的背影——心里——做了一个决定——"她——不是——我的月瑶。我的月瑶——在三千年前——就已经——站在苏衍身边——沉默了。" "这个月瑶——只有十五岁——她——还没有——做出——那个选择。" "我——和她——没有——关系。" **虐点：他在说服自己——不在乎。但——他的手——在发抖。** |
