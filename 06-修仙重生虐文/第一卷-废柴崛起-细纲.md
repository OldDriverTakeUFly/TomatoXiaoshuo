## 段落一：重生（Ch 1–10）
**🎯 任务**：重生开局 + 经脉断裂被嘲讽 + 万古神珠亮明 + 决定不走前世的旧路

| 章 | 标题（暂定） | 情节 / 虐-爆点 |
|----|------|-------------|
| 01 | 三万年 | 前世闪回——万古神渊——黑暗——孤独——三万年的含冤——意识消散前——万古神珠亮了——逆溯时空——睁眼。天璇宗外门弟子舍。16岁的身体。经脉——断了。**虐点：前世的大乘巅峰vs今生的废柴少年——反差。** |
| 02 | 废柴 | 楚玄确认——重生回到了16岁。外门弟子·经脉断裂·修炼不了·被所有人嘲笑。师兄们欺负他——"楚玄·你的经脉废了·还赖在天璇宗干什么？滚回去种地吧。"**虐点：前世剑神vs今生被师兄欺负。** 但楚玄——没有愤怒——只是冷冷看了他们一眼。三万年的含冤——让他的眼神——像一把刀。师兄们——莫名地——后退了一步。 |
| 03 | 神珠 | 楚玄回到舍——盘坐——意识沉入掌心——万古神珠。珠子在——但——昏暗的——力量微弱。前世三万年融合的能量——在逆溯时空中消耗殆尽——只留下了——最核心的——一缕意识。**但——记忆在。经验在。三万年的修炼感悟——全部在。** 他试着用前世的功法引导灵气——经脉——断了——灵气进不去——**但——万古神珠——渗出了一缕极其微弱的——灵泉——** 灵泉——流入断裂的经脉——修复——极慢——但——在修。 |
| 04 | 旧路 | 楚玄回忆前世的路线——16岁经脉断裂→17岁被逐→20岁荒野得天元果修复→25岁筑基回宗→……→大乘巅峰→被诬陷→永封。**这条路——他不能再走。** 因为——前世走这条路的人——最终——含冤而死。**不是路错了——是人错了。** 他信了不该信的人。他做了不该做的"英雄"。**这一次——他不做英雄。他要——先活下来。然后——找到真相。然后——亲手——了结一切。** |
| 05 | 第一个机缘 | 前世记忆——天璇宗后山·瀑布后面——有一个上古洞府——里面有一枚"天元果"——可以修复经脉。前世他是20岁在荒野中偶然得到的——但——实际上——天元果就在天璇宗的后山——他只是——前世——没找到。**今生——他知道位置。** |
| 06 | 后山 | 深夜——楚玄潜入后山——找到了瀑布——找到了洞府——但——洞府有禁制——前世的他打不开——但——万古神珠——可以。神珠的灵泉——渗入禁制——禁制识别了远古气息——解除了。**楚玄进入洞府——天元果——就在石台上——发着金色的光。** |
| 07 | 修复 | 天元果——配合万古神珠的灵泉——修复经脉。**修复过程——极痛。** 经脉断裂了十年——重新接通——像是被火烧——被针扎——从手指到肩膀到全身——每一寸经脉——都在"重连"。楚玄——咬着牙——一声不吭。三万年的含冤——都熬过来了——这点痛——算什么。**经脉——修复。** 他——可以修炼了。 |
| 08 | 从零开始 | 经脉修好了——但修为——炼气一层都没有。前世的大乘巅峰——今生的零。楚玄——不急。他知道——前世的功法虽然强——但——太显眼了——天璇剑诀——一出手所有人都能认出来。他需要——**一套别人认不出的功法。** 万古神珠——推演——将天璇剑诀的核心理念——融入到一套——最普通的——炼气期基础功法中。表面看是基础功法——实际上——每一招都暗藏天璇剑诀的精髓。**隐藏实力——从功法开始。** |
| 09 | 晨练 | 第二天早上——楚玄照常出现在外门的练功场——和所有外门弟子一起——练基础功法。但——他的基础功法——每一招——都暗藏杀机。没人看得出来。师兄们看到他——"哟——废柴楚玄也在练功？练了有什么用？经脉断了——练到死也是炼气一层都到不了。"楚玄——不理他们。**虐点：被嘲讽。** 但——他心里——冷笑。前世的大乘剑神——在练"基础功法"——被一群炼气三层的废物嘲讽。**如果他们知道——他每一招里藏的——是天璇剑诀的杀招——他们会——当场跪下。** |
| 10 | 第一缕灵气 | 三天后——楚玄——炼气一层。比前世的16岁——快了——不是一点——而是——一百倍。前世他经脉修好后——花了半年才到炼气一层——但今生——三天。因为——前世的他——是一个"天才"——但——没有经验。今生的他——有三万年的修炼感悟——每一步——都是最优解。**但——他不能暴露。** 炼气一层——在外门——是最底层——不引人注目。**他故意压着修为——让别人以为他还是"废柴"。** **钩子：外门大比——三个月后——他必须参加——如果垫底——就会被逐出外门。前世他就是这样被逐的。今生——他要——改变。但——不能暴露太多。** |

## 段落二：外门大比（Ch 11–30）
**🎯 任务**：外门大比 + 压制修为暗中碾压 + 不暴露真实实力 + 勉强留在天璇宗 + 遇到第一个"前世的人"

| 章 | 标题 | 情节 / 虐-爆点 |
|----|------|-------------|
| 11 | 三个月 | 楚玄在外门——继续装废柴。暗中——修为已经到了炼气五层。万古神珠的灵泉——让他的修炼速度是普通人的十倍。但他——压着——只在外人面前展示炼气一层的水平。**虐点：明明很强——但必须装弱。** |
| 12 | 欺辱 | 外门一个叫"陈峰"的弟子——筑基初期——最喜欢欺负楚玄。因为楚玄"经脉断裂的废柴"——是最好的"立威对象"。陈峰当众羞辱他——"楚玄——给我跪下——叫三声爷爷——我赏你一颗灵气丹。"**虐点：前世剑神——被一个筑基初期的蝼蚁要求下跪。** |
| 13 | 隐忍 | 楚玄——没有跪。也没有反击。只是——看了陈峰一眼。那一眼——让陈峰——脊背发凉——像被一条毒蛇盯上了。但——只有一瞬间——楚玄就收回了目光——低头走了。**虐点：不是打不过——是不能打。** 打了——就暴露了。暴露了——三万年前的事——可能提前发生。他必须——隐忍。**但——隐忍——比打架——更痛。** |
| 14 | 大比前夜 | 外门大比——明天。楚玄——在舍中盘坐——万古神珠——灵泉涌动——修为——悄悄推到了炼气七层。炼气七层——在外门——已经可以排进前十了。但他——不打算——排进前十。他要——**刚好——不垫底。** |
| 15 | 大比·第一轮 | 外门大比——开始。第一轮——淘汰赛——炼气一层到五层的弟子参加。楚玄——以"炼气一层"的身份——参赛。对手——一个炼气四层的弟子——嚣张——"废柴楚玄？哈哈——我赢了——"楚玄——一招——看似笨拙的"基础掌法"——实则暗藏天璇剑诀的"化剑为掌"——对手——飞了。**爆点：第一场——赢了。但不惊艳——像"侥幸"。** |
| 16 | 大比·第二轮 | 第二轮——对手——炼气五层。楚玄——还是一招——基础功法——但这次暗藏的力道——大了一点——对手的护体灵气——碎了。**观众开始注意他。**"楚玄——经脉不是断了吗？怎么——""他——好像——变强了？""不——只是运气好——" |
| 17 | 大比·第三轮 | 第三轮——对手——陈峰的跟班——炼气六层。楚玄——这次——故意——打了三招——第三招才赢。**不是打不过——是——不能赢得太快——否则会引起注意。** 但——三招——也足够让所有人——惊讶了。"废柴楚玄——过了第三轮？！""他的经脉——好了？""什么时候好的？""不知道——他一直藏着——" |
| 18 | 恨意 | 陈峰——看到了楚玄赢了三轮——脸色——铁青。他之前当众让楚玄下跪——如果楚玄在外门大比中——排名比他高——他——面子全没了。**虐点：恶人不会因为你变强了就放过你——他会更恨你。** |
| 19 | 暗算 | 大比第四轮之前——陈峰派人在楚玄的茶水里——下了"散灵散"——一种能在短时间内散掉灵气的药物。楚玄——前世活了三千年——什么阴谋没见过——他在端起茶杯的瞬间——就闻到了——散灵散的味道。**前世——他可能会怒。今生——他——把茶喝了。** 他故意——中了招。**虐点：明明知道有毒——还喝了——因为——"现在不是暴露的时候。"** |
| 20 | 第四轮 | 散灵散的效果——灵气在两小时内大幅降低。楚玄——在第四轮——面对炼气七层的对手——修为被压到了炼气二层——但——他靠**纯粹的战斗经验**——赢了。前世三千年的战斗经验——即使只有炼气二层的修为——也足以碾压——一个炼气七层的——"天才"。**爆点：修为被压制——但战斗经验碾压——赢了。** 全场——震惊。"他——中了散灵散——还能赢？！""他——到底——有多强？！" |
| 21 | 谁下的毒 | 大比裁判——注意到了楚玄中毒的事——追查——查到了陈峰。陈峰——被取消大比资格——受了宗门惩罚。**但——陈峰——不觉得自己错了——他恨楚玄——更恨了。** |
| 22 | 垫底 | 大比结束——楚玄——排名——外门第三十七名。外门有四十个参赛者——第三十七——刚好——不垫底。他——不会被逐出外门了。**但他——也没有暴露真实实力。** |
| 23 | 留下了 | 外门大比后——楚玄——正式留在了天璇宗外门。前世的他——在大比中垫底——被逐出——流浪了三年。今生——他——留下了。**第一步——改变了。** |
| 24 | 赵狂 | 大比结束后——内门弟子下山巡视——其中——有一个——十七岁的体修少年——豪爽粗犷——笑起来声如洪钟——"哈哈哈哈！外门大比？有意思！"楚玄——看到了他。**赵狂。** 前世——他的兄弟。前世——最后一个出手——一拳打碎他金丹——出手时——眼中有泪——的人。**虐点：赵狂在笑——热情地拍着楚玄的肩膀——"小子！你不错！中了毒还能赢——有骨气！"楚玄——看着他——笑了。但——笑里——有三万年的痛。** |
| 25 | 兄弟？ | 赵狂——对楚玄印象很好——"小子——你叫什么？""楚玄。""好名字！以后——有什么事——找赵哥——谁欺负你——我揍他！"楚玄——看着他的笑容——心里——不知道是什么滋味。**前世——这个人——打碎了他的金丹。但——前世——这个人——出手时——眼中有泪。他——是被蒙骗的。楚玄——不知道——该不该——再信他一次。** |
| 26 | 不信 | 楚玄——决定——**不信任任何人。** 包括赵狂。前世的教训——足够了。"三万年——足够看清楚很多事了。"他——对赵狂——笑——但心里——在记账。**虐点：不是恨——是——不敢再信。** |
| 27 | 暗中修炼 | 外门大比后——楚玄白天装普通弟子——晚上用万古神珠灵泉加速修炼。一个月——炼气九层。两个月——筑基初期。三个月——筑基中期。这个速度——恐怖到——如果被天璇宗知道——会立刻被当成"万年天才"——重点培养。但——楚玄——压着。 |
| 28 | 苏衍 | 楚玄在内门附近——第一次看到了——**苏衍**。16岁——内门弟子——天璇宗公认的"下一代第一人"——英俊·温和·所有人都喜欢他。楚玄站在远处——看着苏衍和同门说笑——他——前世——是苏衍的师兄——手把手教他剑法——苏衍叫他"师兄"——然后——三千年后——亲手锁住了他。**虐点：看到仇人——但仇人现在对你笑——还在叫你"师兄"。苏衍看到了楚玄——"楚玄师弟？外门的？我听说你大比表现得不错——加油——"笑——温和——完美。楚玄——"谢谢师兄。"心里——冷。** |
| 29 | 月瑶 | 楚玄在天璇宗的集市上——看到了——**月瑶**。月华宫圣女——15岁——跟着师父来天璇宗交流——白色衣裙——清冷如月——不与任何人多话。楚玄——看着她——前世的——爱人。前世——她站在苏衍身边——没有说话——没有替他辩解——沉默——沉默——沉默。**虐点：最深的爱变成了最深的伤。他看着月瑶——月瑶没有看他——擦肩而过——像两个陌生人。而前世——这个"陌生人"——是他用命爱过的人。** |
| 30 | 第一卷·段落二收束 | 楚玄回到舍——盘坐——万古神珠亮。修为——筑基中期。他——看着窗外——天璇宗的夜空——繁星。前世——他在这片星空下——发誓要守护苍生。今生——他在这片星空下——发誓——**不再做任何人的棋子。** 但——就在这时——万古神珠——忽然——震动了一下——珠子里——浮现了一段——他前世没有见过的——信息——**关于——苏衍——和仙界——的——一条暗线。** 苏衍——16岁——已经——和仙界——有联系了？**钩子：苏衍的背叛——不是三千年后——而是——从一开始——就在——布局。** |

## 段落三：暗中崛起（Ch 31–55）
**🎯 任务**：暗中修炼到金丹 + 获取更多前世机缘 + 苏衍暗线加深 + 月瑶再次出现 + 陈峰报复

| 章 | 标题 | 情节 / 虐-爆点 |
|----|------|-------------|
| 31 | 暗线 | 万古神珠的信息——苏衍体内——有一缕——仙界灵气。这意味着——苏衍——在16岁——就已经被仙界的人——"标记"了。楚玄——前世——不知道。今世——知道了。但——他不打算——现在就揭穿。因为——他还不知道——仙界——是哪位仙王——为了什么。**他需要——更多的信息。** |
| 32-35 | 前世机缘 | 楚玄利用前世记忆——在附近的山脉中——找到了三个前世遗漏的机缘：一处灵石矿脉（隐藏在瀑布后面）、一株千年灵药（长在悬崖石缝中）、一本残缺的上古功法（刻在一块碎玉上）。这三个机缘——让他的修为——从筑基中期——飞速推进到了——**筑基巅峰**。 |
| 36 | 陈峰的报复 | 陈峰——被大比惩罚后——不甘心。他家里有钱——花重金买了一把"灵器"级别的宝剑——请了一个内门弟子做后盾——准备在"外门秋猎"中——暗杀楚玄。**虐点：弱者的恶意——比强者更阴毒。** |
| 37 | 秋猎 | 外门秋猎——在天璇宗附近的"万兽林"中举行。弟子们需要在林中猎杀妖兽——以妖兽晶核计分。楚玄——参加了。表面看——他是炼气九层的"普通弟子"。实际上——筑基巅峰。 |
| 38 | 暗杀 | 陈峰带着三个帮手——在密林深处——围堵了楚玄。"楚玄——上次大比——你害我丢了面子——今天——我要你——死在这里——"他拔出灵器宝剑——三个帮手也亮出了武器——**虐点：被围杀。前世剑神——被四个蝼蚁围杀。** |
| 39 | 爆发 | 楚玄——看着他们——叹了口气。"你们知道吗——前世——也有人——在密林中——围杀我——" "什么前世？你在说什么——" "那些人——比你们强一万倍——但他们——也死了。" **楚玄——不再隐藏。** 筑基巅峰——灵气释放——陈峰等四人——被灵气压迫——**同时——跪了。** 不是被打——是——灵气压迫——膝盖——自动弯了。**爆点：前世剑神——不再隐忍——一个眼神——蝼蚁跪地。** |
| 40 | 废 | 楚玄——没有杀他们——但——废了陈峰的修为。一掌——打散了陈峰的灵脉。陈峰——永远不能再修炼了。"你——你废了我的修为——""前世——有人废了我的金丹——和你比——你很幸运——你只是——不能修炼了——而我还——活着。"楚玄转身——走了。陈峰——瘫在地上——嚎啕大哭。**爆点：碾压。不是杀——是——废。比杀更狠。** |
