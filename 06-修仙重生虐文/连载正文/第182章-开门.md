# 第一百八十二章 开门

窝棚里那个问题，林尘没有当场答。

他说："带我上山。到了封印跟前，我答。"

贾管事带他上山，走的是夜路——封山期间，白日有巡，夜路，避人。一千八百级石阶，两级警戒，三道岗。每一道岗，贾管事亮一次执法堂的令。第三道岗的弟子，认出了林尘——封山两个月，山上的旧人都还在，"林尘"这个名字，在山上，从不曾真的淡过。没人声张，只是守岗的弟子，默默地，把火把举高了些，替他照路。

后山，禁地深处。

越往里走，林尘的脚步越慢。不是累——是怀里的东西，越来越沉。星铁在夹层里，像有热气，一点一点，渗出来。神珠在他识海里，也静得反常，静得像在——听。

瀑布后面，上古洞府，那棵墨玉色的树——都过了。再往深处，是山腹里凿出的一条甬道。甬道两壁，嵌着一盏一盏的镇石灯，灯焰幽幽的，照着满地的灰——灰从上头的裂缝漏下来，落进山腹，落在两万年的石阶上，一层白。

甬道尽头，是那道封印。

林尘在甬道口，站住了。

封印是一面"墙"。墙高十丈，宽三十丈，横在山腹的尽头，把整条甬道，堵得严严实实。墙面上，上古的阵纹，一层压着一层——如今，七成的纹路，黯成了死灰，只有零星几道，还残着微光，像烧到尽头的香。

墙前，坐着一个人。

一个白发的老人，盘膝，背对着他们，正对着那面墙。老人的背影，比四年前又小了一圈，道袍空空地垂着。他的双手按在地上去，渡劫期的本源，正一缕一缕，往那面墙里，渡。

墙，在"吃"他的本源。吃得极慢，可是不停。

"宗主。"贾管事低声唤，"人，带到了。"

老人的本源，缓缓收了。他转过身来。

四年前那个在殿影里等了三万年、说出一声"对不住"的老人，如今，脸上又多了四年的沟壑。可那双眼睛，看见林尘的一瞬，亮了——亮得像枯了两万年的井底，忽然渗进一线泉。

"回来了。"他说。

"回来了。"林尘说。

两人隔着几步，站定。老人上上下下，把他看了一遍——看到脚上的鞋，看到腰间的剑，看到背上的画卷，最后，落在他怀里鼓鼓的夹层上。

"上头，"老人问，"什么样？"

"很黑。"林尘说，"四千里的洞。走出来，很亮。"

老人点了点头，没再问。他指了指身后的墙："它这两个月，安静了。"

"我每回渡本源进去，它——让开。让我的力，落在最要紧的纹上。"老人说，"它在，帮我。"

"帮我撑它自己的——牢。"

林尘走到墙前。

近了，那些拓片上的抓痕，就在眼前——密密的，层层叠叠，从墙的"里面"，往外抓。三万年。最深的那道，横贯整面墙，深可容指。那两个字，就在痕的末端，一笔一划，笨拙，苍老：

"开门。"

林尘站在墙前，看了很久。

然后他闭上眼，把神珠请出来——这一次，不是渗，不是锔。是"贴"。神珠的本相，那颗暗金色的珠，浮出他的眉心，轻轻地，贴在了那面墙上。

墙上，静了一息。

两息。

然后——墙的深处，传来了一个震动。

不是撞。不是抓。是一种极慢极慢的、整面墙都在颤的——抖。像一头困了不知多少万年的巨兽，隔着墙，感到了什么，把额头，轻轻抵了过来。

【林尘。】神珠的声音，在他识海里，颤着。

【我认识它。】

"谁？"

【魔帝。】神珠说，【上个纪元，跟天道争锋、败了、被镇在这里的那位。】

【它认出我了。】

【它在问——】

【它问：锔子，你是来补天的吗？】

林尘站在墙前，手贴着那面冰冷的墙。墙那头的颤，透过掌心，传进他的骨头里。

他在心里，问神珠："怎么答？"

【照实答。】

林尘便照实答。他的神识，顺着神珠贴墙的那一点，渡了进去——不深，就渡到墙的那一头，像隔着一扇门，说一句话。

"是。"他说，"我来补天。"

"不是来补你。"

"天裂了，我在补。你这道封印，镇着裂的根——我补天，绕不开你。"

墙那头，静了很久。

久到贾管事和宗主，都不自觉地上前了一步。

然后，那道颤，又起来了。这一次，颤里有"话"——不是声音，是极简的、一缕一缕的神念，从墙那头，断断续续，渡过来。神念苍老，钝，像不会说话的人，一个字一个字，往外挪：

"补天……好。"

"补……完……"

"放……我……"

"出……去……看……看。"

四个字，渡完，墙那头的存在，安静了下去。那面墙上的阵纹，黯着的七成里，忽然，有一成，极缓极缓地，又亮了一丝。

林尘收回了手。

他转过身。宗主和贾管事，站在他身后，两张脸，都白着——他们看不见神念的往来，可他们看得见墙的变化，看得见那一成重新亮起来的纹。

"它说什么？"宗主哑声问。

林尘把那四个字，译给了他们。

"'放我出去，看看。'"

山腹里，静了很久。

宗主走到墙前，抬起手，按在墙上——按在那两个字，"开门"上。老人的手，抖着。

"三万年了。"他说，"我把它当仇家的牢，当了三万年。我把镇它，当还债——还我儿子的债。"

"如今你说，它在帮我撑墙。你说，它要的，是出去看看。"

老人回过头，看着林尘，眼里的东西，翻江倒海："小友。你告诉我——"

"这道门，开，还是不开？"

林尘没有立刻答。

他走到墙跟前，蹲下来，就着镇石灯的光，看那两个字。看那个"开"字最后一笔——那一笔收尾的地方，刻痕分了好层，深浅不一，是一遍一遍，重刻的。刻了多少遍，数不清。

他伸出手，指腹，抚过那一笔。

"宗主。"他终于开口，"门，我开。"

"但现在不开。"

"天上那道裂，是它的牢撑着的根——它的牢，是天裂的'压舱石'。贸然开门，压舱石挪了，裂，先崩。"他说，"我去补天。补到裂能自己站住了——我回来，开这道门。"

"开门之前，"他站起来，"请宗主，做一件事。"

"什么？"

"从今天起，"林尘说，"别再叫它'封印'了。"

"叫——'门'。"他说，"墙上那两个字，它刻了三万年。它管这儿叫门，咱们管这儿叫牢——"

"一个东西，两个名字，隔着三万年的仇。"

"从今天起，统一了。"他说，"都叫，门。"

宗主站在墙前，很久很久。

然后，这位渡劫期的、镇了这道"门"三万年的老人，对着墙，深深地，躬下身去。

"老夫，"他说，"失礼了。"
