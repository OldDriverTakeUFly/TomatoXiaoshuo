# 第二百五十五章 风

界上群像，第四章，讲一阵风。

这，年，春，天，营，地，刮，了，一，场，风。

风，不，稀，奇，。仙，界，边，缘，有，风，——虚，空，流，动，带，起，来，的。

稀，奇，的，是，这，场，风，——暖。

那，天，"清，晨"，风，从，西，边，来。吹，过，营，地，的，时，候，正，在，早，灶，边，熬，粥，的，人，愣，了，一，下：

灶，边，的，人，习，惯，了，边，缘，的，风，。那，风，凉，。这，阵，风，吹，过，来，——像，凡，界，春，天，晒，过，被，子，的，那，种，暖。

"这，风，"她，说，"，从，哪，儿，来？"

没，人，答，得，上。

风，吹，了，一，整，天。

吹，过，菜，畦，吹，过，花，屋，吹，过，鞋，山，吹，过，辰，时，岩。陆，先，生，——他，如，今，还，站，着，站，到，了，第，两，万，多，年——那，天，在，岩，上，站，着，让，风，吹，了，一，个，时，辰。

下，来，的，时，候，他，说，："这，风，我，认，得。"

"您，认，得？"

"门，开，那，天，"他，说，"，山，腹，里，出，来，的，那，阵，——跟，这，个，一，个，味。"

"一，个，味？"

"暖。"陆，先，生，说，"，灶，膛，饭，熟，的，味。"

消，息，报，到，秦，苍，那，儿。秦，苍，发，信，问，了，两，界，书，那，头，。

半，个，月，后，回，信，到，了，——小，方，的，徒，弟，渡，的，信，里，附，着，临，江，天，文，台，的，一，段，记，录：

"某，年，某，月，某，日，凡，界，东，境，暖，风，异，象。"

"风，起，西，北，——天，璇，山，方，向。"

"当，日，天，璇，山，腹，'门'，墙，——守，墙，执，事，录，：'墙，温，一，日。'"

"同，日，——"信，的，最，后，一，段，写，"，同，日，天，上，'井，口'，巡，值，仙，官，录，：'金，线，明，一，日。'"

"三，处，同，日。"信，写，"，台，里，的，老，先，生，批，：'此，风，自，金，线，来。'"

"'天，道，长，好，了，的，地，方，'老，先，生，批，"，'开，始，——换，气，了。'"

"换，气？"营，地，的，人，围，着，那，封，信，看，。

"就，是，"叶，青，看，完，信，想，了，很，久，说，"，伤，口，愈，合，的，时，候，皮，肉，新，长，——会，发，热。"

"发，热，的，地，方，"她，说，"，血，通，了。"

"血，通，了，"她，说，"，就，有，热，气，往，外，冒。"

"这，个，风，"她，说，"，就，是，天，道，那，道，新，长，的，肉，——冒，的，热，气。"

营，地，的，人，听，完，都，没，说，话。

过，了，很，久，有，个，年，轻，人，问，："那，这，风，——会，一，直，刮，下，去，吗？"

"不，会。"叶，青，说，"，伤，好，透，了，就，不，发，热，了。"

"那，时，候，"她，说，"，就，是，——"

她，没，说，完。

阿，蛮，在，边，上，接，了，下，去，他，的，声，音，很，平：

"好，了。"

"伤，好，透，了，"他，说，"，不，发，热，不，疼，不，痒，——就，是，好，了。"

"好，了，之，后，"他，说，"，没，有，痕，迹，吗？"

"有。"叶，青，说，"，痕，迹，在，里，头。"

"金，线，"她，说，"，就，是，痕。"

那，天，晚，上，营，地，的，人，把，那，场，暖，风，记，进，了，册，子。

记，完，小，鱼，在，册，页，的，角，上，画，了，一，笔，：

一，条，极，简，单，的，线，。线，的，一，头，画，了，个，小，小，的，圈。

有，人，问，她，画，的，什，么。

"金，线，"她，说，"，和，井，口。"

"风，从，这，儿，出，来，"她，指，着，那，个，圈，"，往，我，们，这，儿，吹。"

"往，凡，界，吹。"她，说，"，往，山，上，吹。"

"往，——"她，把，那，条，线，往，册，页，的，边，上，延，了，延，"，所，有，有，人，的，地，方，吹。"
