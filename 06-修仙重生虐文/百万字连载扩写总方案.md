# 《万古第一神》百万字连载扩写总方案

> **版本**：v1.0（2026-08-14）
> **目标**：从96章压缩稿（25.3万字）扩写为300章连载版（90万~105万字）
> **依据**：《最终版总文档》原始设计——三卷·各100章·每章约3000字
> **原则**：压缩稿是"故事骨架定稿"，连载版是"血肉版"。情节主线、人物关系、反转结构、结局一律不变。

---

## 一、现状与差距

| 项目 | 压缩稿（现状） | 连载版（目标） |
|------|--------------|--------------|
| 章节数 | 96章 | 300章 |
| 总字数 | 25.3万字 | 90万~105万字 |
| 单章字数 | 约2600字 | 3000~3800字 |
| 战斗描写 | 一笔带过（"三招赢了"） | 全程拆解（起手/攻防/转折/决胜/观战反应） |
| 心理描写 | 点到为止 | 双主角内心戏成章 |
| 群像 | 主线人物为主 | 配角各有支线与视角章 |
| 修炼描写 | 结果式 | 过程式（灵气入体/瓶颈/心魔/突破全程） |

**差距约75万字**，来源构成：
1. 现有96章就地深化（每章平均加500~800字质感）——约6万字
2. 战斗场面全细化（大比/秋猎/万兽谷/内门大比/终战）——约15万字
3. 新增支线章与群像章——约40万字
4. 修炼细节与心理描写——约10万字
5. 新增曲折（灵泉眼争夺/天元果博弈/青石镇/仙界边缘扩展）——约6万字

## 二、五大扩写手法（写作时对照使用）

### 1. 战斗细化——"一场战斗写三章"
每场重要战斗按五段式展开：
- **战前**：双方站位、灵气状态、地形、观战者议论、心理盘算
- **交手前几合**：招式拆解（功法第几式、灵气运转路线、破绽在哪）
- **转折**：受伤/底牌/地形变化/意外介入
- **决胜**：一招定胜负的完整慢镜头
- **战后**：观战者反应、伤势、心理余波、江湖传言

范例：压缩稿"三招赢了"→ 连载版拆成"起手试探—对手轻敌—第五式灵气逆行—看台哗然—对手教练脸色"整场戏。

### 2. 曲折增设——"每个事件加两道弯"
- 灵泉眼：不只是"发现灵泉"，加"原主人是谁—觊觎者上门—林尘如何智取不留名"
- 天元果：加"奖励规则—多方博弈—黑手—果落谁家的意外"
- 秋猎：加"外门恶意的暗算—妖兽潮—救人暴露风险"
- 原则：**弯路必须服务主线**（身份悬念/善意链条/异常积累），不为曲折而曲折。

### 3. 修炼细节——"境界是有手感的"
每个境界突破写全程：灵气从哪来（呼吸/丹药/灵泉）、走哪条经脉、卡在哪一关、心魔幻象是什么（全部取自前世记忆——虐点内嵌）、突破后身体的具体变化（听觉/夜视/灵气视）。
神珠的作用逐级显形：温养→加速→逆天→代价（越强越冷）。

### 4. 心理描写——"双主角双内景"
- **林尘**：恨与不敢恨、看故人不能认、防备融化全过程、力量增长的冷漠自查
- **楚玄（少年）**：废柴的倔强、对"隐形人"的好奇与依赖、挡刀那刻的义无反顾
- 心理章不超过连续两章，必须用事件/动作打断，避免拖节奏。

### 5. 群像扩展——"每个人都有来处"
压缩稿已立住的配角，连载版每人补：**一场来源戏 + 一场高光戏 + 一场后记戏**。
- 天璇宗：胖子（家世与家书）、赵教头、食堂阿姨、守门老人、杂役老头
- 万兽谷：小方、柳青、老孙、张铁锤、张铁剑（佣兵队各有前史）
- 仙界边缘：叶青、废墟里的两人、等太阳的人
- 后记群像：小翠、散修们、被传下去链触达的每一个人

## 三、连载章节标准（每章出厂规格）

1. **字数**：3000~3800字（正文净字数，不含标题）
2. **开头**：三行内进入场景或冲突，不写天气开场
3. **节奏**：每章至少2个节拍（事件推进+情绪推进各一）
4. **章末**：必须有钩子（悬念/反转/情感暴点/新信息），禁止平收
5. **文风**：保留断句张力，但**破折号密度减半**——对话与动作用干净短句，场景与心理用饱满段落；每章至少一处"可截图转发"的金句或画面
6. **格式**：章内标题与文件名编号一致（修正压缩稿错位问题）
7. **每10章一个小高潮，每30~35章一个大高潮（事件章）**

## 七、文风规范（连载版统一执行）

1. 保留核心文体：短句、留白、断行造张力
2. 破折号密度较压缩稿**减半**：压缩稿平均每章120+处，连载版控制在50处以内；场景描写、战斗描写、群像描写改用完整段落
3. 对话要有"人物指纹"：赵狂粗直带喘、苏衍温和得体句句藏针、月瑶清简、胖子碎嘴热心、铁山大嗓门、清漪冷而柔
4. 每章一个"名场面"或"金句"
5. 虐点节奏：连虐不超过三章，虐后必给一口气
6. 禁止上帝视角剧透反转（尤其月瑶献祭、太虚苦衷）

## 八、工作流

1. 写作顺序：按连载章号顺序推进，一篇一篇写满
2. 每完成一篇：对照本方案表格核内容 → 下一个
3. 里程碑：每完成10章 git commit 一次并推送
4. 旧`正文/`目录保留为压缩定稿参考，不再改动
5. 连载版目录：`06-修仙重生虐文/连载正文/`
6. 全卷完成后跑格式转换脚本出发布版（脚本另行适配连载目录）
