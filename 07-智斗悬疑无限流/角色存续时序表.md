## 二、角色个体卡(按入队序)

### 季默(主角·始终在场)
- **能力阶段**:ch1-6 困惑(不知有能力) → ch7-11 破解(三句规律) → ch12-23 伪装「预感」 → ch24-27 顿悟(信念) → ch28-42 驾驭(选择三句) → ch43-51 终局
- **战斗水平**:ch10 首杀(闭眼抡) → ch12 学"挡" → ch15 船钩 → ch16 钩人 → ch25 首次见血 → ch37+ 有战斗力但始终非主攻
- **注意事项**:ch27 后嗓子劈过;ch42 命名「三缄」后不再数句数

### 江屹(始终在场)
- **状态**:ch4 手灰(回声红蚀) → ch30 两更疤愈(留白痕) → 后续灰痕为永久标记
- **能力**:不疼+超体魄(始终)
- **持道具**:ch35 起持长明灯

### 沈知遥
- **入队**:ch1
- **状态**:全程感知+共感
- **死亡**:ch27(死于半句"他不是预感,他是——")
- **归来**:ch50
- **⚠️ ch28-49 期间只可出现在回忆/墙面/回响中,不可有活体行为**

### 条纹衬衫(无名者)
- **入队**:ch1
- **死亡**:ch4(心死,不再回溯)
- **归来**:ch50("我想起来了,我叫什么")
- **⚠️ ch5-49 期间不存在**

### 曹贵发
- **入队**:ch7
- **能力**:借贷(ch17 觉醒)
- **状态**:ch17 半条命打款 → ch21 催熟失忆(部分) → ch40 拒当 → ch42 终借枯萎死亡
- **归来**:ch50("满上了")
- **⚠️ ch43-49 期间不存在;ch21 后记忆残缺,只记得"胖发"等碎片**

### 周会计 / 石头
- **入队**:ch7
- **死亡**:ch11(镜奴,由江屹送别)
- **归来**:ch50
- **⚠️ ch12-49 期间不存在**

### 陈霜
- **入队**:ch7
- **死亡**:ch26(替阿禾挡石壁)
- **归来**:ch50("救回来,一些")
- **⚠️ ch27-49 期间不存在;ch12-25 在场但戏份薄,可加**

### 萧烈
- **入队**:ch12(烈马并入)
- **能力**:燎原(火)
- **状态**:ch26 断筋(双腿残) → 后续轮椅/教头
- **始终在场至终局**

### 杜衡 / 温纫 / 骆峰(烈马三人)
- **入队**:ch12
- **死亡**:ch26(替萧烈挡刀,一前一后)
- **归来**:ch50
- **⚠️ ch27-49 期间不存在**

### 阿禾
- **入队**:ch19
- **能力**:共生(植物→死木→网络)
- **状态**:ch40 被夺舍 → ch42 散入草木"未归" → ch43-49 身体在沙发上沉睡 → ch50 醒来"吵死了"
- **⚠️ ch43-49 期间不可有正常行为(她是植物/沉睡状态);ch40-42 夺舍期间她是Boss载体**

### 佟老(棋爷)
- **入队**:ch35
- **能力**:复盘
- **⚠️ ch1-34 期间不存在**

### 阿岩
- **入队**:ch35
- **能力**:垫
- **⚠️ ch1-34 期间不存在**
