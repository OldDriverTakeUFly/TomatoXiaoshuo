# 《全球副本：从签到SSS级异能开始》人物卡与设定集

> 写作时以此为准。所有人设、关系、口头禅、行为逻辑统一。

## 一、主角

### 🔥 林默（主角）

| 项 | 内容 |
|----|------|
| 年龄 | 24 岁 |
| 外貌 | 短寸头、五官棱角分明但不帅、皮肤偏黑（常年跑外卖晒的）、身高180cm、体型精瘦但肌肉线条清晰（常年体力劳动的产物）；末世后穿深色工装+战术靴；眼神永远平静，只有在杀人的时候会变冷 |
| 末世前身份 | 外卖骑手。每天跑14小时，月入不到5000，住城中村8平米的隔断间，被房东催租、被客户投诉、被平台扣钱。父母早亡，无兄弟姐妹，无女朋友 |
| 异能 | SSS级【万界吞噬】（签到获得） |
| 性格 | 不圣母、杀伐果断、有底线、务实、话少。能动手就不BB。不在乎别人的看法——末世前他已经受够了被看不起，末世后他只在乎"活下去、活得更好" |
| 口头禅 | "别废话。" |
| 雷区（绝不可崩） | ❌ 不会因为可怜敌人而手软 ❌ 不会为了女人影响战斗节奏 ❌ 不会主动惹事但绝不怕事 ❌ 不会当舔狗 ❌ 不会对弱者滥杀（有底线） |

**人物弧光**：
- 前期：被看不起的底层→用签到碾压所有人→享受"打脸"的快感
- 中期：开始承担"领袖"的责任——不是为了道德，是因为"手下的人越多，我活得越好"
- 后期：从"为自己活"变成"为一群人活"——但嘴上永远不承认
- 终极：全服第一。不是因为想当第一，是因为"不当第一就会死"

**写作要点**：
- 林默的心理活动要少——他是"行动派"，不是"思考派"
- 他看人的标准只有一个——"有没有用"。但有"用"不只是战斗力，忠诚、后勤、情报都算
- 他不会主动解释自己的行为——做了就是做了，别人怎么看不重要
- 他对队友的态度——嘴上冷淡，实际护短。"我的人，谁动谁死"——但不会把这句话说出口
- 签到时的反应——前期会惊讶/兴奋，中后期变成"嗯，又是好东西"的淡定（侧面展示成长）

## 二、核心团队

### 🛡️ 赵铁柱（第一个小弟·肉盾）

| 项 | 内容 |
|----|------|
| 年龄 | 28 岁 |
| 外貌 | 粗犷、络腮胡（没女频霍北那么夸张，更偏军人气质）、180cm、膀大腰圆；穿旧迷彩服+军靴；左手缠着绷带（末世前工地受伤留下的习惯） |
| 末世前身份 | 退伍兵（武警退役），退役后在工地搬砖。老婆跟人跑了，没孩子 |
| 异能 | D级【力量强化】（第一卷觉醒）/ 后期升至 B级 |
| 性格 | 憨厚、忠心、打架不要命、脑子不太灵光但执行力极强。林默说什么他就做什么——不是因为傻，是因为他判断"跟着林默能活" |
| 口头禅 | "老大你说打谁？" |
| 定位 | 肉盾 + 忠诚打手 + 据点军事主管 |
| 与林默关系 | 第一卷Ch5被林默救下后死忠追随。他的忠诚不是盲目的——林默救了他的命，带他变强，他认这个"老大" |

**写作要点**：
- 赵铁柱的"憨"是表面——他是退伍兵，有战斗直觉和纪律性，不是傻大个
- 他的搞笑来源于"反差"——一个粗犷壮汉在林默面前像个小弟一样乖
- 他在战斗中永远冲在最前面——因为他信林默"老大不会让我白死"

### ❄️ 苏晚晴（红颜知己·军师）

| 项 | 内容 |
|----|------|
| 年龄 | 22 岁 |
| 外貌 | 马尾辫、五官精致偏冷感（不是甜美型是清冷型）、168cm、身材匀称但不夸张；穿深色冲锋衣+工装裤；眼神永远带着审视和冷静 |
| 末世前身份 | 985大学计算机系大四学生，年级第一，保研名额在手。家境普通，靠自己努力 |
| 异能 | C级【冰系】（第一卷Ch8副本内觉醒）/ 后期升至 A级 |
| 性格 | 冷静、聪明、独立、外冷内热。不会因为别人强就盲从——她只认"道理"和"实力" |
| 口头禅 | "你有计划吗？"（她永远在问计划，和林默的"别废话"形成反差） |
| 定位 | 军师 + 远程输出 + 战略规划 |
| 与林默关系 | 从"看不起底层外卖骑手"→"被实力折服"→"敬佩"→"暗恋但不表达"。慢热型。**男频女主是战友，不是花瓶** |

**感情线处理（男频铁律）**：
- ❌ 不写黏腻恋爱戏
- ❌ 不写争风吃醋
- ❌ 不让苏晚晴因为感情影响战斗
- ✅ 偶尔的关心——"你受伤了"→"没事"→（默默递上药品）——点到为止
- ✅ 偶尔的醋意——别的女角色接近林默时——但她不会表现出来，只是多看一眼
- ✅ 战斗中的默契——不需要语言，一个眼神就知道配合

**写作要点**：
- 苏晚晴的"冷"不是无情——是理性。她计算过：跟着林默存活率最高
- 她和林默的对话永远简短——两个人都是"话少"类型
- 她的作用是"让林默看起来更牛逼"——她的聪明才智反过来衬托林默的直觉和果断

### 💊 宋小萌/小蘑菇（治愈系·团宠）

| 项 | 内容 |
|----|------|
| 年龄 | 16 岁 |
| 外貌 | 圆脸、大眼睛、双马尾、155cm、瘦小；穿oversize的连帽衫（末世前从家里跑出来穿的）；总是缩着肩膀，像一只受惊的小动物 |
| 末世前身份 | 高一学生。和奶奶一起住，父母在外地打工。末世时和奶奶走散 |
| 异能 | E级【治愈系】（第一卷Ch19觉醒）/ 后期升至 C级 |
| 性格 | 胆小、善良、依赖林默但不矫情。她知道自己在末世里毫无战斗力——所以她拼命做"有用的事"——治疗、照顾、做后勤 |
| 口头禅 | "林默哥……我、我害怕……"→（后期变成）"林默哥，我来治！" |
| 定位 | 治疗 + 团队粘合剂 + 被保护对象 |
| 与林默关系 | 被林默从噩梦副本救出后死忠追随。对林默的感情是"依赖+崇拜"——不是男女之情，更像"哥哥" |

**写作要点**：
- 小蘑菇的成长线是"从胆小到勇敢"——前期只会哭，后期敢站在战场上救人
- 她不拖后腿——治愈系太珍贵了，她是团队的核心保障
- 林默对她的态度——嘴上不说，但行动上永远把她放在最安全的位置
- **禁止把她写成拖累主角的累赘**——男频大忌

## 三、反派

### ⚡ 秦天（天选者首领·第一卷主要反派）

| 项 | 内容 |
|----|------|
| 年龄 | 30 岁 |
| 外貌 | 精英感——高大、英俊、穿着考究（末世后也穿定制战术服）、永远一丝不苟；眼神带着居高临下的傲慢 |
| 末世前身份 | 某知名企业CEO。年少有为，习惯了"我是最优秀的" |

| 性格 | 傲慢、控制欲强、慕强但只认自己是"最强的"。他组建天选者是因为他真心认为"末世应该由强者统治" |
| 与林默关系 | 一开始"看不起"（外卖骑手？）→"好奇"（连续第一？）→"忌惮"（三招秒了自己三号）→"敌对"（招揽被拒）→"决裂"（炼狱副本被反杀） |

**反派设计要点**：
- 秦天不是无脑恶人——他有他的"逻辑"（强者统治弱者是天经地义）

- 他不会在第一卷死——他被林默反杀后逃走，留到第二卷继续作梗
- **虐反派节奏**：Ch31打脸雷鹰→Ch37反杀偷袭→Ch45-47炼狱正面对决反杀秦天。三次交锋，一次比一次狠

### 📋 反派模板（可复用）

男频无限流的反派必须遵循统一的"打脸公式"：

```
反派登场：看不起林默（因为他的底层出身/人数少/装备差）
    ↓
嘲讽："你也配？"
    ↓
林默出手：碾压（一招/三招/秒杀）
    ↓
围观者震惊：全服频道炸了
    ↓
排行榜数字：第1名 / 比第二名快X小时
    ↓
反派跪地求饶/逃跑
```

**反派分级**：
| 类型 | 跨度 | 打脸方式 |
|------|------|----------|
| 路人嘲讽者 | 1-2章 | 当场秒杀 |
| 副本内竞争对手 | 1个副本(3-5章) | 排行榜碾压 |
| 势力型反派（如天选者） | 跨1-2卷(50-100章) | 多次交锋→最终决战 |
| 天才型反派 | 全书 | 长期对抗→终极对决 |

## 四、世界观设定

### 4.1 末日游戏系统

| 设定 | 说明 |
|------|------|
| 触发时间 | D-0，全球红色天空10秒后，所有手机收到绑定短信 |
| 副本频率 | 每3天开放一次 |
| 副本时长 | 副本内12小时 = 现实1小时 |
| 死亡规则 | 副本内死亡 = 真正死亡（不可复活） |
| 副本难度 | 普通(白)→困难(绿)→噩梦(蓝)→地狱(紫)→炼狱(橙)→神级(红) |
| 评分系统 | F→E→D→C→B→A→S→SS→SSS（影响奖励品质） |
| 排行榜 | 副本评分榜/战力榜/签到天数榜/击杀榜/国家区域榜 |

### 4.2 签到系统（主角独有）

| 签到类型 | 触发 | 品质 | 备注 |
|----------|------|------|------|
| 日常签到 | 每天一次 | 白~绿 | 必得，保底 |
| 副本隐藏签到 | 副本内特定地点 | 绿~红 | 需探索发现 |
| 连击签到 | 连续N天 | 7天蓝/30天紫/100天橙 | 断签归零 |
| 特殊签到 | 首杀Boss/排名第一 | 橙~红 | 里程碑触发 |
| 首签奖励 | 每个新副本首次签到 | 必出蓝以上 | 鼓励探索 |

**品质分级**：白(普通)→绿(优秀)→蓝(稀有)→紫(史诗)→橙(传说)→红(神话)

**暴击机制**：5%概率触发暴击，品质提升2级。白色→紫色。绿色→橙色。蓝色→红色。

### 4.3 异能等级体系

| 等级 | 称呼 | 占比 | 说明 |
|------|------|------|------|
| F | 觉醒期 | 80%的人类 | 刚觉醒，能力微弱 |
| E | 稳定期 | 15% | 可实战 |
| D | 成长期 | 4% | 中坚战力 |
| C | 精英期 | 0.8% | 精英 |
| B | 强者 | 0.15% | 一方霸主 |
| A | 王阶 | 0.04% | 区域顶级 |
| S | 皇阶 | 极少数 | 国家级 |
| SS | 帝阶 | 全球数十人 | 大陆级 |
| SSS | 神阶 | 全球数人 | 全球级 |

### 4.4 现实世界——末日后

| 项 | 说明 |
|----|------|
| 社会秩序 | 彻底崩溃。政府/军队在末日游戏初期损失了大量人口（第一次副本死亡率约30%），残余力量退守军事基地 |
| 变异兽 | 末日游戏开始后出现。和副本里的怪物类似但等级更低。前期的变异兽多为F~E级 |
| 货币 | 纸币废弃。硬通货是：食物、药品、武器、晶核（可用来强化异能）|
| 据点/基地 | 幸存者自发组建。有异能者的据点更容易存活。林默的据点从十几人发展到几百人 |

### 4.5 天选者组织

| 项 | 说明 |
|----|------|
| 性质 | 由一批高级异能者组建的精英组织。信奉"末世应由强者统治" |
| 首领 | 秦天（A级·重力控制） |
| 核心成员 | 3个A级 + 8个B级 + 几十个C级。总人数约200人 |
| 据点 | 城北某商业大楼改建的"天选者基地" |
| 理念 | "普通人是累赘，只有强者才配活。" |
| 与林默关系 | 第一卷：敌对→被反杀→暂时蛰伏。第二卷：卷土重来 |
| **设计意图** | 天选者是林默的"反面镜子"——同样的"强者逻辑"，但林默的强是"签到公平分配来的"，天选者的强是"天生优越感"。两人本质对立 |

## 六、写作备忘

### 6.1 男频人设铁律

1. **主角不圣母**——救人可以，但必须有"利己"逻辑（"救你有好处"或"救你因为你是我的队友"）
2. **女角色不拖后腿**——苏晚晴和小蘑菇必须有自己的战斗力/功能性，不能只是"被保护对象"
3. **队友不背叛**（至少第一卷不背叛）——男频读者讨厌"背叛"桥段，队友忠诚是基本盘
4. **反派不能蠢**——反派的失败是因为实力差距/低估主角，不是智商下线
5. **主角不解释**——做了就是做了，不对任何人解释自己的动机和行为

### 6.2 和女频文的人设差异

| 维度 | 女频《空间女皇》 | 男频《全球副本》 |
|------|------|------|
| 主角性格 | 冷静+护短+偶尔柔软 | 冷静+务实+绝不心软 |
| 感情表达 | 有柔软的一面（对姜糖/裴夜） | 几乎不表达感情（行动代替言语） |
| 队友关系 | "家人"感 | "上下级"感（老大和小弟） |
| 女角色 | 姜糖=闺蜜/陈雪=战友 | 苏晚晴=战友+暗恋/小蘑菇=妹妹 |
| 反派 | 陆衍（渣男/绿茶） | 秦天（精英傲慢/慕强逻辑） |
| 打脸逻辑 | "你伤害过我，我让你后悔" | "你看不起我，我碾压你" |
| 主角口头禅 | （无固定，偏冷静叙述） | "别废话。" |

### 6.3 签到描写的仪式感（每章签到必须有的格式）

```
『叮！签到成功！』
『恭喜获得——[品质颜色]·[物品名称]！』
『效果：[具体效果描述]』

（暴击时追加——）
『⚠️ 金色暴击触发！品质提升两级！』
『[原品质] → [暴击后品质]！』
```

**写作要点**：
- 每次签到描写都要用这个格式——形成读者期待
- 品质颜色必须标注——读者最爱看颜色升级
- 暴击时要有"金光""音效"的描写——仪式感拉满
- 连击签到要强调"连续X天"——数字递增本身就是爽点
