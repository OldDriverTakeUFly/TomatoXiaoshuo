## 一、逐章摘要（Ch01–Ch44）

| 01 | 正经小卖部 | 凌晨三点过路凶（行会编号辛-41）进街掀翻三个垃圾桶，周正拎后颈像丢一袋过期米丢出街口，只留"垃圾桶归位""扫帚，八块"——功劳当场滑给提灯夜巡的退休守夜人蔡长明；老葛行车记录仪"永远差半秒"（循环覆盖+车头朝外拍不到）。开篇双柱一章立住。 |
| 02 | 那晚的事 | 视频进夜班司机群，L1 圈炸锅"扶槐街有高人"，逐帧永远差半秒；周正给六楼宋奶奶扛煤气罐，功劳滑给同电梯快递员+一袋橘子（无功劳律日常面首秀），平台又吞五星好评（"七个工作日核实中"）；打烊面卧两个蛋（温情记号立）。钩子：白半仙起卦"灯火大旺"。 |
| 03 | 罗盘转圈 | 白半仙假扮买烟踩点，罗盘在店门口疯转——不指人，指店；判词出炉"店是阵眼，守阵的是守夜人蔡长明——前辈高人"（L2 版误解链立起）；猫一屁股坐上罗盘，白半仙不敢挪；同业群建词条"扶槐街·待核"。 |
| 04 | 拜见前辈 | 白半仙率 L2 小队正式拜码头堵住老蔡，老蔡"我就是睡不着出来遛弯"却张了张嘴没否认——退休五年头一回有人记得他是干什么的（被记住的滋味）；白半仙在老槐树系一枚小铜铃"借地留响"（行里礼数，为 Ch20/Ch28/Ch40 埋点）；钩子：老蔡在落灰梆子前站到深夜。 |
| 05 | 守夜人 | 老蔡前史章：蔡家三代守扶槐街，安街铃、提灯步、梆子点，三十年真手艺；五年前那晚街尾出事他慢了半步，孩子受惊全家搬走，他把梆子挂回墙；碗底压钢镚、绕街两圈才睡得着的规矩立。钩子：伸手要碰梆子又缩回来。 |
| 06 | 本店概不营业外业务 | 名声连锁反应：街坊排队沾福气、阵眼萝卜、"照片里永远没有老板"同城帖；周正挂九字手写告示被小满吐槽字丑（"正经小卖部，字不重要"），猫扒告示垫窝（只针对他清单开张）；白半仙把"蔡长明"写进名录"隐世"栏——七年来头一个新名字。小循环①闭环。 |
| 07 | 和棋 | 老蔡溜达到街尾修鞋摊拿主意"我该不该认"，老严头不接话只摆棋，一盘和棋；老蔡自己憋出"我就……再守守看"；老严头落最后一子说出全卷主题句"灯亮着就行，谁点的要紧吗？"；收摊时多看了一眼小卖部的灯（身份线起埋）。 |
| 08 | 挂铃 | 低烈度单元首例：纺织厂宿舍齐家闹蹲户，老两口失眠半月，街坊抬老蔡去；他硬着头皮挂安街铃走安街步，当夜宅安——周正全章零出场，这一单是他自己的真功夫；立"挂铃不收钱，收一碗米"规矩、"印子留着给东西留脸"等手艺细节。 |
| 09 | 八块钱 | 安街铃火了，老蔡来进货铜铃："进价八块，卖你八块。""你这店正经吗？""正经。"（"八块"体系立）；货源=社区团购按"庙里用"上货；连夜编铃小满帮缠绳，叔侄式斗嘴收工；钩子：同业群"蔡长明"词条热度第一。 |
| 10 | 跟踪 | 小满发现叔打烊后"倒垃圾"四十分钟，跟踪之——巷口风一吹她连自己跟的是谁都描述不出来、23 张照片全糊（无功劳律日常面正面戏：目击者永远描述不出他）；回家夜宵掐点温热在桌上，她不问了；错题本背面实体化"我叔不对劲·证据列表"，第一条：猫对他太随便。 |
| 11 | 同业会 | 白半仙带老蔡赴 L2 茶馆交流会，被架上"隐世高人"座如坐针毡；推座、白水、"不是我送的"被解读为借势（高人行为学三连）；聂大夫提问转出真功夫，老蔡讲安街步满堂喝彩"提灯步，实证"；佟半仙抛"城西点名闹得凶，扶槐街安生得反常"（弱接口首埋）。 |
| 12 | 聂大夫 | 非人兽医聂大夫抱绝食三天的小灵物白团子（档案号丙-11，灵目·待考）来"借你家汤，一用"；周正舀汤顺手把纸箱摆正冲灯，当场开炫——立"账上没有的人，闻着是干净的"（无味设定）；聂大夫记档"店主，普通人，汤头不错。暂记"，收入出诊箱久查夹袋；钩子：摆正箱子那一下她回头看了第二眼。 |
| 13 | 澄清失败 | 老蔡社区茶话会公开澄清，烟盒小抄三行没念完——后厨邪火窜起（蹭香火的小东西撑着了），周正送酱油途中解绳放帘断风（6 行＜次日找零 10 行），众目睽睽"老蔡抬手火灭"；澄清变添彩，骑虎难下完成体；钩子：提灯三十年头一回觉得沉。 |
| 14 | 买烟的 | 全卷关键伏笔章：黄昏穿旧呢子大衣的清瘦"客人"（老貉人形）进店买大前门，说话慢眼睛亮；周正递烟找零提醒"吸烟有害健康"一气呵成，真心没认出（"看不清"铁律第一次正面戏）；猫从冰柜炸上货架毛成蒲公英；临走深深看猫一眼"畜生道行不浅"；街口清点"名，好得很——虚得正好"。 |
| 15 | 夜权 | L2 规矩科普章（白半仙夜陪老蔡讲古）：守夜人行当、夜权（一条街夜里的名分归守夜人）、讨名三试（灯、铃、步）一夜不破名归守夜人、破了街归它；结论砸下老蔡的名已虚高到招灾，白半仙后怕"是我把他写进名录的"；钩子：城外老貉备好帖子正式动身。 |
| 16 | 备战 | 韩执事（白半仙师叔，81 岁）电话报信"貉下山"（说三句挂电话的台词风格首立）；老蔡进小卖部不是求助，是坐着说说话："接是规矩，不接也是规矩。""哦。""……来份关东煮。"周正夜里把店门口灯换成更亮一盏、又打市政电话报修街口路灯（善后式温柔）；钩子：猫夜夜蹲老蔡家房脊"像换了个岗"。 |
| 17 | 翻箱底 | 温情底章：擦三件套——竹骨纱面灯笼（内壁朱砂敕字掉七成、他爹笔迹、灯芯座包浆四十年）、选黑沉老铃应三试、解开红绳落灰五年的梆子；心结全揭：慢半步的真因不是眼花，是心里先怯了"别是冲我来的"；豁口粗瓷碗（孩子的练步碗）洗净盛水上桌；小满闲话带出：孩子前年搬回纺织厂宿舍四楼朝东，上夜班；老蔡楼下守到十一点半，"别耽误人家"没叫住人。 |
| 18 | 演武 | 凌晨街口老蔡练步，周正拎垃圾袋站桩当靶、喂招如打电线杆；顺手扶正两处（"左脚到得慢"＋拨正外撇脚尖——不是懂功法，是看了十年老蔡巡街看熟了）；猫蹲花坛尾巴打拍子；钩子：讨名帖贴上老槐树（黄糙纸竖排"三日后。亥时。"，无落款只一枚湿四趾爪印，一夜无风纸自己响）。 |
| 19 | 下帖 | 全街"看不懂但大受震撼"；老蔡读懂：月晦夜三试；白半仙们要来助阵，老蔡按规矩回绝"讨名是守夜人一个人的事，人多即破"；老严头一句"狗是五个趾"+年轻时"在谁家账本上见过四趾印"欲言又止（身份线二埋）；白半仙红着眼圈掏出账本（"名是债"首次实写）。 |
| 20 | 攒人情 | L2 圈不肯干看着：捐符捐阵堆满老蔡家，人情全记在白半仙账本上（账本特写，笑中带冷）；老蔡把符纸分挂街口只留一盏自己的灯；小满送护膝"我叔说，夜凉"，老葛把车停街口"顺路，今晚就在这守"；老严头连夜无偿给步鞋加胶底"压得住"——全街没一个人说破自己在等什么。 |
| 21 | 前夜 | 留白章（写短写静）：周正照常营业到打烊只做三件事——换灯泡、给猫添双份鱼、紧遮阳棚的绳；街坊以为大扫除；打烊时老蔡路过，两人隔着灯点了下头谁也没说话。 |
| 22 | 月晦·灯 | 老貉至，先试灯：阴风扫街灯焰缩成豆，老蔡提灯步稳、安街步护焰，灯不灭；穿插店内视角：周正理货，隔一堵墙什么也"听"不见（感官普通人），全凭猫的耳朵炸不炸判断外面顺不顺——"看不清"铁律在高潮也不破。 |
| 23 | 月晦·铃 | 老貉坏规矩：遣三只小夜叉分袭街口街尾看客（金记两口子、夜归街坊）；千钧一发——周正在门口收棚（解活扣、摘铁钩、风掀棚，全文约 90 字全是收摊日常），连棚带绳罩下三只拍平、两只顺排水沟溜走；画面只有猫看见；老葛从棚边探头"这棚，质量中啊"（笑点垫在险上）。 |
| 24 | 月晦·步 | 老貉本体上身，化出半条街长的影子压顶；老蔡梆子不乱、步子不撤，一步一声四百米把影子钉在原地——这一战全靠他自己，周正在店内刷关东煮的锅没动；Ch18 伏笔回收（左膝"咔"、右脚等半拍）；天光起，梆子最后一响。 |
| 25 | 退名 | 规矩裁断：灯亮、铃在、步全——名归守夜人；老貉自述四十年前来过一回、名实相符未下帖；临退回头深深看小卖部："这条街的灯……不像是你的手艺。"——离真相最近的一句飘进夜风没人接住（老蔡耳鸣只捡到一个"灯"字，猫打喷嚏）；老蔡蹲街口哭得像刚下夜班的人，哭完扶墙站起来（停一秒就走）；他看了眼卷起的棚，一言未发。 |
| 26 | 谢客 | L2 来贺要改名录"特级"，老蔡当众划掉"隐世高人"，一笔一画写回"守夜人·扶槐街"（卷一主题落锤）；人群误读"特级之上！自度！返璞归真"（高人行为学再夯）；白半仙烧掉人情账页"守下来的名，不用还债"，又把债一笔一笔誊到自己名下"名是我给您添的柴。柴钱，我还"（转型动机源）；同业亲见"全街路灯灭、独店灯不晃"再固"阵眼"，白半仙张了张嘴什么也没说（存疑未言）；韩执事电话"划下去了？""好。"；当晚老蔡睡了退休五年头一个整觉。 |
| 27 | 睡了个整觉 | 战后恢复：老蔡睡到日上三竿被画眉吵醒（新道具画眉：失眠最重那年买的，一人一鸟各自熬了五年）；小卖部照常，周正给老蔡留的豆浆从一杯换成一碗（全程无台词，他就是多盛了一勺）；二婶家小子喜宴十月十二正式递帖头一排留座；钩子：扶槐街的名字在江湖上开始换一种走法。 |
| 28 | 老貉余音 | 老貉北撤三十里、影子薄如纱、败帖袖册又添一张，自圈新规矩离那条街远点；道行物圈传话"扶槐街，灯硬。绕着走"（传得最凶一版：连布都靠不住）；老葛翻记录仪"又是差半秒"学精了不声张，"走扶槐"成司机群暗号、新人入行仪式、平安成交通资源；小卖部夜宵卖空三回；蹭香火小东西回来闻——甜味没了"名实相称的街，没便宜可占"（卷二街面异动哨兵）；城边新过路凶望灯掉头。 |
| 29 | 各守各的 | 桥东物业三千→五千重金请出山，老蔡一句"守夜人不串街"拒单；转身开另一件事：每周三老槐树下摆开铜铃梆子讲安街步（首批七人：齐婆老姐妹团、吴老师、逃早自习的孩子）；白半仙想操办收费被拒（伏 Ch37/40）；章末：远处一个下夜班的年轻身影。 |
| 30 | 半大孩子 | 二婶闲话立身份："路裁缝家的，大名路生""夜班的"，前年一个人搬回、城东分拣仓库夜班；老蔡课上认出他、讲着讲着忘了词；"梆子怎么拿？""手心朝上，托着，别攥""木头认人，得焐""我焐了三十年，你比我快"；"顺路"（下夜班怎么走都绕不到这树底下）；老蔡回家把豁口碗又拿了出来。 |
| 31 | 对不起 | 豁口碗相认："这碗，豁口能记水线"；迟到五年的"对不起"终于说出口（写了三回撕了三回，说出口只有三个字）；路生的回答是全书最软一笔："那晚啊……我只记得有条街的灯特别亮，我是一路看着灯，走回家的。"（他记住的是灯，不是惊吓）；"碗，搁您这儿。搁得住"；碗口朝上收回柜底，挨着裂口老铃。 |
| 32 | 错题本 | 小满模考数学 61 分，叔侄互辅翻车：周正被导数题难住（"智力普通人"铁律的温情喜剧面），沉默三秒"……扫码还是现金"；小满笑到打鸣，错题本写"我叔，除了数学（和扛煤气罐），什么都会"；钩子：进货单上多了一项"口算题卡·自用"。 |
| 33 | 猫的照片 | 初雪夜小满起夜关窗，看见老板娘踩雪上房——雪地上没有脚印，落爪处雪平如未碰；连拍八张全糊成一团白；回屋在证据列表添第四条，从头看一遍，整页撕掉塞进炉膛——"日子比真相舒坦"；留最后一张白照片设屏保"拍的雪"；清晨周正摸猫，毛是干的，"没多想"（猫线周正不知情）。 |
| 34 | 铜钉 | 老严头歇摊一天"看老朋友"，归来铁皮箱东北角多一枚照老钉新配、铜油捂过的锃亮铜钉——修鞋用不上铜钉，铜钉是挂东西的钉（挂铃、挂牌）；老蔡看懂了半秒"各家有各家的老朋友"，没问；与周正第三十一盘又是和棋，各自笑了一下，"你那个棚，换新绳了""换得好"；他绕路在老槐树铜铃下站了一会儿——全部只埋不揭；雪地脚印一步是一步。 |
