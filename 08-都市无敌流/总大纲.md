# 《店长今天也不想出名》（工作标题）
# 都市无敌流 · 半隐秘超自然 · 总大纲

> **定位**：都市无敌流 · 半隐秘超自然 · 群像单元剧 · 高密度喜剧 + 烟火温情
> **篇幅规划**：200 万字 + · 长期连载（每卷 40-60 章，10-15 万字）
> **发布平台**：番茄小说（都市频道 / 轻小说向）
> **调性参考**：《一拳超人》的画风差 ×《深夜食堂》的人情味 ×《齐木楠雄的灾难》的日常灾难管理
> **与本项目其他作品区隔**：
> - 区别于 `05-男频末世无限流`（签到碾压爽文、现实+副本双线）——本作**无系统、无双线、零生存压力**。
> - 区别于 `06-修仙重生虐文`（女频虐恋）——本作**无重生、无恋爱主线**。
> - 区别于 `07-智斗悬疑无限流`（窒息智斗、生存博弈）——本作**无阴谋主线、无生存威胁，主打"造神游戏"式全知喜剧与小人物弧线**。

## 一、一句话简介

周正开了家小卖部，只想准点开门、准点打烊。可这家店有点邪门：在店门口摔跤的邪祟、被顺手喂饱的凶兽、莫名了结的百年恩怨——功劳最后总落在别人头上：退休大爷被当成隐世高人，落魄保安一战成名，连隔壁小孩都进了异人名册。全城知情者的圈层一层层往上捅，谁也没想到，所有传说的起点，只是个想安静看店的普通人。

---

## 二、核心爽感公式

> **超自然麻烦上门 → 周正顺手解决（事越大他越顺手，画面越平淡）→ 无功劳律生效、功劳滑向当场的背锅侠 → 背锅侠人生拐弯、被名利围猎 → 善后工程（周正把连锁反应一件件按回去）→ 温情收束（背锅侠找到自己的真实价值）→ 知情者圈层捅破一层 → 进入下一个循环**

**爽感与笑点类型：**
- **全知造神爽**：读者全程知道真相，看周正随手"种"出一个个传说，看各圈层抢着解释他——每一层误判都错得离谱、且自成体系、互相打架。
- **画风差喜剧**：灭世级危机 vs 老板找零钱的口吻。灾难写得越认真，他表现得越平淡，落差越大越好笑。
- **误解链喜剧**：L1 说他是都市传说，L2 算出他是普通人，L3 档案里只有"重案率反常低的小卖部"，L4 的猫知道真相但不会说话——每个圈层的错误结论都要立得住、要记档、要互相碰撞。
- **善后工程喜剧**：不留名的代价是连锁反应，主角把小事一件件按回去的过程必然蚊子级失控。
- **温情留人**：背锅侠弧线 = 小人物被命运突然青睐后的失重与落地；小店是深夜食堂式的收容处。

**长线期待管理**：读者最长的钩子是"他什么时候被发现"——**分层小揭，不许憋死不解**（详见 3.3 谜底拼图节奏）。

**每 3-5 章一个小循环闭环（番茄节奏）**：①一次麻烦上门 ②一次画风差解决 ③一次误解或善后的笑料 ④一个钩子（圈层异动/班底暗线）。

## 三、世界观设定

### 3.1 半隐秘世界：知情者圈层金字塔

普通人不知道超自然存在，但"知道的人"远比想象中多——圈层递进，一层捅破一层。

| 层级 | 是谁 | 对周正的认知 |
|---|---|---|
| **L0 普通人** | 绝大多数市民 | 扶槐街那个小卖部老板 |
| **L1 撞见者** | 短视频拍客、夜班出租车司机：见过一次，多半当成幻觉 | "那晚的事"里始终描述不出脸的目击者 |
| **L2 从业者** | 驱邪师、风水先生、拍卖行、兽医（给非人类看病的那种） | 判读结果：普通人——而且怎么算都是 |
| **L3 组织层** | 官方"异常事务科"、地方行会 | 档案里只有一家"重案率反常低"的小卖部 |
| **L4 老家伙们** | 活了很久的东西：百年蛇、镇宅兽、老鞋匠 | 猫知道；老鞋匠知道但不说 |
| **L5 天机** | 世界本身 | 唯一"看见"他的层级——看见的方式是一片空白 |

**圈层规则：**
1. 每层都以为上面没几层了——这是半隐秘世界得以维持的原因，也是喜剧的来源。
2. 周正天然卡在所有卜算之外：**L5 之下没人能定位他**。这是"世界不知道他"能成立两百万字的设定保证。
3. 圈层只能一层一层捅破：每一卷捅破一层（或在一层内部横向扩展），不许跳层。

### 3.2 无功劳律（天生霉运 · 天地记账规则）

**这是本作金手指的另一半——"反向面板"。**

- **法则**：天地账本记不住周正。凡他做成的事，功劳必然滑向在场能被天地"看见"的另一个人；四下无人时，记给最倒霉的目击者或一个合理的第三方。**他自己无解**（喜剧素材：他曾试图留名，锦旗最后送给了店猫）。
- **日常面**：小事诸事不顺——排队必被插队、刚洗的车必下雨、好评总被平台吞掉、目击者永远描述得出背锅侠却描述不出他。但霉运从不伤他分毫、从不真正坏了大事：它是"天地的记账手续费"。
- **与卜算豁免的咬合**：正因天地"看不见"他，账才记不到他头上——无功劳律不是独立设定，而是无敌规则的自然后果。**他越强，越无名。**
- **情感面**：这是他孤独的来源——无敌，却不被世界记得。全书最深的温情线：总有一些"账本之外"的存在能看见他——店猫、老鞋匠，以及终卷某个凭人心看见他的普通人。**灯不需要被感谢，亮着就行。**

### 3.3 长线谜底：定盘星（全书暗线 · 分卷揭露）

**谜面**：周正为什么天生无敌、天生无名？

**谜底**：这个世界每隔许久，会自然生出一颗"**定盘星**"——天地用来镇宅的人。天生无敌、无欲无求；"想开店"是刻在骨子里的本能：**给世界留一盏灯**。天地需要他镇宅，但不需要他被记住——所以账本上没有他。

**街尾修了四十年鞋的老鞋匠，是上一颗定盘星。** 两个无敌的人下象棋，互相让棋，和了三十年——这是全书最深也最温柔的暗线。

**谜底拼图节奏（长线期待管理，防憋死）：**
- 卷四：老鞋匠身份揭晓一半（他"不简单"实锤，定盘星之名未出）。
- 卷六：老家伙们的口径浮出——"天地留人镇宅"的古老传说。
- 卷八：无功劳律的来历=账本规则，主角自己首次拼出真相轮廓。
- 终卷：上一颗星的交接（老鞋匠把摊子收了，把"关门的钥匙"交给周正）+ 人心看见他（全书唯一一次无功劳律被"人"豁免）。

## 四、金手指：天生无敌

### 4.1 绝对无敌的边界

- 任何物理攻击无效；力气无上限；不会受伤、不会死、不老（衰老速度忽略不计）。
- 免疫诅咒、精神干涉、**因果与卜算指定**：一切探测、面相、数据模型、天机推演，都把他判读为"一个普通人"。
- 天生如此，没有代价，没有来源仪式——来历即 3.3 定盘星谜底。

### 4.2 性格限制（喜剧引擎的一半）

- **不留名，功劳归别人**：一半是天性淡泊，一半是无功劳律代劳——他连"想认领"都认领不了。
- 帮完人最怕三件事：**锦旗、采访、下跪**。
- 口癖："与我无关""随便""扫码还是现金"。

### 4.3 张力守恒定律

主角没有生存压力，张力百分之百来自：
1. **背锅侠的处境**（他们会被名利围猎、会被架上去下不来——真正的悬念在他们身上）；
2. **善后工程**（不留名引发的连锁反应，比怪物难缠）；
3. **圈层逼近**（知情者金字塔一层层朝他这层捅，L3 的档案越来越厚）；
4. **无功劳律的情感反噬**（他想被一个人记住，而世界不答应）。

## 五、主角设定：周正

- **名字梗**：名字最正常，人最不正常。
- **年龄外貌**：三十岁上下，长相普通到"目击者描述不出他"（无功劳律的一部分）。常 年一件套头卫衣系一条围裙，围裙上印着店名。
- **店**：老城区扶槐街中段的"**正经小卖部**"——招牌就这五个字，因为周正说"我开店很正经"。而全城最不正经的传说都从这里开始。街口一棵老槐树，街尾是老鞋匠的修鞋摊。
- **行为模式**：准点开门准点打烊；商品按标价，赊账记账本；凶兽来了先问"买点什么"；解决完天大的事，回头继续理货。
- **情感内核**：不冷，只是怕谢。他的温柔全部藏在"顺手"里——顺手挡的灾、顺手留的豆浆、顺手按回去的命运。全书他唯一想要的东西：**有一个人，能不靠天地账本，凭自己认出他。**

## 六、核心配角（常驻班底 · 滚雪球）

> 双螺旋结构：单元背锅侠是卷主角（见第七、八节），常驻班底是贯穿全书的暗线。表现好的背锅侠卷末可转常驻，班底像滚雪球一样慢慢长大。

### 6.1 起步班底（卷一登场）

- **周小满**（复读侄女，L0）：高考失利来投奔叔叔，店员。普通人视角担当 + 吐槽役；全书"观众嘴替"，负责替读者问"叔你刚才是不是……"并被糊弄过去。
- **周师傅**（夜班出租车司机，L1）：常客，每晚来买红牛。见过"那晚的事"，坚定认为退休大爷是隐世高人——误解链喜剧担当，逢人就讲大爷传说，越讲越玄。
- **店猫"老板娘"**（实为百年镇宅兽，L4）：来蹭饭兼观察。不说话，行为喜剧担当；全书少数"看见"周正的存在之一——它对周正的态度（蹭他、盘他、给他叼死老鼠）本身就是给读者的暗示。
- **老鞋匠**（街尾，上一代定盘星，L4→谜底层）：修了四十年鞋。与周正下棋三十年全是和棋。全书最深暗线，卷四起逐步揭晓。

### 6.2 卷内转常驻

- **卷三起**：异常事务科卧底调查员（假扮新店员），L3 视角担当——官方档案与街头传说的对撞机。

## 七、双螺旋卷结构（叙事主架构）

### 7.1 每卷公式

> **新背锅侠（卷主角）＋ 捅破一个新圈层 ＋ 常驻班底暗线推进一步 ＋ 长线谜底掉一块拼图**

### 7.2 背锅侠类型学（小人物图谱 · 每卷一个职业宇宙）

退休大爷、落魄保安、代驾司机、殡葬师、外卖站长、拆迁办科员、流浪猫救助站站长、夜市摊主、社区网格员……每个背锅侠都是一个"被命运突然青睐的普通人"，弧线模板：**被架上去 → 失重（名利/责任/围猎）→ 在周正顺手的托底下落地 → 站住属于自己的位置**。

### 7.3 结构铁律

1. 每卷卷主角两型：**背锅侠型**从 L0 或 L1 起步，卷末停在"知情但说不出口/说了没人信"的位置；**体制型**（如卷三卧底）从 L3 进入，卷末停在"所有数据正常、所有直觉不正常"的位置。
2. 每卷只捅破一层圈层，圈层内可横向扩人（新的从业者、新的科室）。
3. 常驻班底每卷至少一条暗线实质推进（猫的身份、老鞋匠、卧底的档案、侄女的复读）。
4. 谜底拼图按 3.3 节奏投放，不提前不跳票。

## 八、全书阶段规划（卷）

- **卷一 · 隐世高人**：退休大爷在店门口"降服"邪祟（实为周正顺手），异人圈来拜码头——大爷将错就错又心虚，最后真正接过"守街"的担子。温情落点：被架上去的位置，他站住了。L1→L2。谜底：无（埋线期）。
- **卷二 · 一战成名**：落魄保安"独退凶兽"视频爆火，被网红公司签走，名利反噬——善后工程最重的一卷。温情落点：保安退还所有打赏，回岗亭上班，但这次是他自己选的。L2→L3。
- **卷三 · 卧底店员**：异常事务科盯上"重案率反常低"的扶槐街，派调查员进店卧底——官方视角与街头传说大对撞，班底扩充。温情落点：调查员的报告写不下去，因为"所有数据都正常，所有直觉都不正常"。L3 内部戏。
- **卷四 · 老家伙们**：百年蛇过街、镇宅兽聚会、老鞋匠身份揭晓一半——L3→L4。谜底拼图第一块落地。
- **卷五起（开放）**：背锅侠类型学轮换 + 圈层横向扩展；卷六/卷八按谜底拼图节奏推进；终卷：交接与"人心看见他"。

## 九、写作铁律（喜剧 + 温情调性）

1. **主角三不**：永不解释、永不邀功、永不被拍到正脸（无功劳律自动运作，不是他躲，是世界不记他）。
2. **画风差公式**：危机越大，他越平淡。灾难题材用买菜口吻写；他解决灭世级麻烦的篇幅，不许超过他找零钱的篇幅。
3. **误解链要记账**：每个圈层、每个配角的误判都要立得住、自圆其说，全部记入《回顾与线索账》——后续碰撞的笑料和揭示的爽感全从这里长出来。
4. **笑料不打人物**：喜剧来自处境，不来自羞辱角色。任何笑点过后，人物不许比笑之前更矮。
5. **温情落点铁律**：每卷的落点必须落在背锅侠"站住"的瞬间——不煽情、不解释、不下判词，镜头停一秒就走。
6. **无功劳律不可打破**：全书唯一豁免留给终卷"人心看见他"，此前任何卷、任何配角都不许真正识破（可以无限接近，然后滑开）。
7. **章法**：单章 2000-3000 字；每 3-5 章一个小循环闭环；每卷 40-60 章。

## 十、书名与待定项

**书名候选（终选待定，工作标题用①）：**

**待定项（进入卷一细纲前决定）：**

- 城市命名与地理细节（当前：虚构老城区"扶槐街"，城市名暂用"临江市"）。
- 背锅侠卷一~卷四人选复核（当前：大爷/保安/卧底/老家伙们）。
